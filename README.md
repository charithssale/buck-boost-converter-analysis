Project:
Design and simulation of a Buck-Boost DC-DC Converter capable of converting a 24V input source to multiple output voltages including 9V, 12V, and 30V.

Tools Used:
- LTspice
- MATLAB
- Power Electronics Analysis

Key Topics:
- MOSFET Characteristics
- Duty Cycle Analysis
- Converter Ratio Derivation
- Efficiency Analysis
- Voltage Ripple Evaluation
- DC-DC Converter Design
